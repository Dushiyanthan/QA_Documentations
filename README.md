# QA_Documentations
QA documentation repository with Test Plans, Test Cases, and Test Summary reports. Showcases structured manual testing and validation for software applications.
---

## Repository Structure

Each project has its own folder with PDFs:  

/ProjectName
- TestPlan.pdf
- TestCases.pdf
- TestSummary.pdf

---

## Purpose

Showcases structured **manual testing** and **functional validation** practices applied to software projects. All artifacts reflect documented QA activities.
